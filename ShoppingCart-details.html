Detalles de ShoppingCart Web

Información de proyecto

  • Categoria: Desarrollo web
  • Cliente: Sistema en venta al publico
  • Fecha de proyecto: septiembre, 2024
  • URL del sitio: ShoppingCart

Sistema web de venta de productos, con la posibilidad de crear usuarios, categorias y productos asi como agregarlos al carrito de compras. Este sitio fue desarrollado con ASP .Net MVC con HTML5, CSS3 y JavaScript, utilizando Bootstrap 5 y librerias como es Datatables para la construcción de tablas HTML avanzadas. Para el backend se crearon las APIS con C# para su posterior consumo con Fetch API, y se utilizó Entity Framework para la conexión a la base de datos. La base de datos fue implementada en Azure Sql Server, con la funcionalidad de Stores Procedures para gestionar los cambios realizados en cada categoría en tiempo real.
